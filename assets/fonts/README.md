# Custom font folder

둥글둥글한 한글 폰트를 직접 적용하려면 웹폰트 파일을 이 폴더에 넣고 파일명을 `omg-round.woff2`로 맞추세요.

현재 CSS 상단에는 @font-face 예시가 주석으로 들어 있습니다. 아래 경로에 폰트를 넣고 주석을 해제하면 적용됩니다.

```txt
assets/fonts/omg-round.woff2
```

폰트 파일이 없으면 NanumSquareRound, Pretendard, SUIT, Apple SD Gothic Neo, Noto Sans KR 순서로 대체 표시됩니다.

권장 포맷: WOFF2
